## 🛠️ Tech Stack

- **Backend:** Java, Spring Boot, Spring Data JPA / Hibernate (built in **IntelliJ IDEA**)
- **Frontend:** React with **Vite**, **Bootstrap 5**, HTML5, CSS3, **React Router**, **Axios** (built in **VS Code**)
- **Database:** MySQL
- **Tools:** Git, GitHub

---

## 🚀 Quick Start

### Prerequisites
- JDK 17+
- Node.js & npm
- MySQL running locally on port 3000

### 1. Backend Setup (Spring Boot)
1. Ensure your local MySQL server is running and your database is created.
2. Open the backend project in **IntelliJ IDEA** (or run via terminal):
   ```bash
   cd backend
   ./mvnw spring-boot:run

   2. Frontend Setup (React + Vite)
Open the frontend folder in VS Code:

Bash
cd frontend
npm install
npm run dev
